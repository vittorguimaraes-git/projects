# Projects

A collection of projects built while learning and practicing software development. This repository will grow as new projects are added.

## Projects

### To-do List

A command-line task manager written in Python. It lets you add, list, edit, complete, and remove tasks, each with a priority.

To run it, use Python 3.14 or later:

```bash
cd src/todo_list
python todo_list.py
```

Follow the prompts to manage your tasks. Task data is stored locally in `tasks.json`.
