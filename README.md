## 🧩 Projects

### ✅ To-do List

A simple command-line task manager for keeping everyday tasks organized.

- Add, list, edit, complete, and remove tasks
- Set a priority for each task: high, medium, or low
- Save tasks locally in a JSON file

## ⚡ Get started

Requires Python 3.14 or later.

```bash
git clone https://github.com/vittorguimaraes-git/projects.git
cd projects/src/todo_list
python todo_list.py
```

Follow the prompts to manage your tasks. Your task data is saved to `tasks.json` in the current directory.
